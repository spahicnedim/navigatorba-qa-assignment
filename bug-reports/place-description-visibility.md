# 🐞 No Visual Cue for Extended Description

## Summary
Users can't tell that more description is available unless they hover with the mouse.

## Steps to Reproduce
1. Go to a place detail page.
2. Scroll to the “Place Description” section.
3. Hover over the paragraph.

## Expected Result
If the text is truncated, show ellipsis (`...`) or a “Read more” link.

## Actual Result
Extra content appears only on hover without any visual cue. No indication that more text is available.

## Severity
🟡 Medium – UX inconsistency

## Suggestion
Add ellipsis (`...`) or “Prikaži više” link.

## Environment
- Arc V1.50.1
- macOS 15.4.1
