# 🐞 Cannot Revert from Split Service to Single Working Hours

## Summary
When user selects "Split Service" under working hours, there's no clear option to revert to single schedule.

## Steps to Reproduce
1. Go to Create New Place form.
2. Select Split Service for working hours.
3. Try to return to normal schedule.

## Expected Result
User should be able to toggle back to single working hours easily.

## Actual Result
No option to revert. UI placement is unintuitive.

## Severity
🟡 Medium – Usability blocker

## Suggestion
Add a “Clear” or “Back to Single Schedule” button.

## Environment
- Arc V1.50.1
- macOS 15.4.1
