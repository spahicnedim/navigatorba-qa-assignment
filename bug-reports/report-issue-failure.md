# 🐞 Cannot Submit Feedback via “Report Issue”

## Summary
After filling out the Report Issue form, error message appears upon submission.

## Steps to Reproduce
1. Open any place detail page.
2. Click on “Report Issue”.
3. Fill out the form and submit.

## Expected Result
Submission confirmation and message sent.

## Actual Result
Error: “Unable to send your feedback. Please try again.”

## Severity
🔴 High – User feedback broken

## Environment
- Arc V1.50.1
- macOS 15.4.1
