# 🐞 Unexpected Error on Place Creation

## Summary
When attempting to create a place with valid data, error message is shown even though form appears correctly filled.

## Steps to Reproduce
1. Go to Create New Place form.
2. Fill in all required fields with valid data.
3. Submit.

## Expected Result
Success message confirming place creation.

## Actual Result
Error appears: “Some unexpected error occurred. Please try again.”

## Severity
🔴 High – Core functionality blocked

## Notes
Issue may be backend or validation related.

## Environment
- Arc V1.50.1
- macOS 15.4.1
